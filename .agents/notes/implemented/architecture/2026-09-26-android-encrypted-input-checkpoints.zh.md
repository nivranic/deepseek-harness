# Agent Note: Android 在显式提交前保存按主体隔离的输入

Status: implemented

[English](2026-09-26-android-encrypted-input-checkpoints.md) | 中文

## 问题

进程退出可能丢失人类输入，以及重试结果不确定的 prompt 所需的请求身份。凭据文件能证明身份，但不能恢复草稿。自动恢复排队修改会剥夺用户检查结果的机会。其他 Host 密钥或设备授权的输入不能成为当前主体的草稿。

## 决策

Android 进程为每组 Host id、固定指纹和设备 id 持有独立的加密输入文档。版本 2 保存 Session 草稿与未确认的原始 prompt 意图，包含文本、请求 id 及有序文件列表，列表记录每个文件的回执 id、附件 id、名称和字节数。文档还保存按 Session/交互/修订标识的 Question 答案，以及最后查看的普通 Session。文档不保存凭据、源 URI、文件字节或 Host 对话事件。应用使用独立的 Keystore 别名，加密文档上限为 1 MiB。读取拒绝所有其他版本、未知字段、无效 UTF-8、重复行或文件回执、无效文件元数据、主体不匹配，以及同一请求身份关联不同完整意图；不可读取的字节保持原样。

共享状态持有者串行合并写入。每次显式 prompt 或 Question 回复在发出前等待输入保存；保存失败阻止 RPC，并提供显式保存重试。待确认 prompt 独立保留原始文本/文件完整意图及请求 id，不受更新后的输入区草稿影响。修改文本或有序文件列表会为输入区生成新请求 id；显式重试保留待确认意图的原始 id 与回执。明确成功确认和匹配的 Host user-message 回执只清理已接受意图及完整内容完全匹配的草稿。重新观察会核对回执，不重放修改。Question 关闭或修订替换移除过期答案；保存期间事件客户端变化会阻止发送过期回复。

同目录临时文件与强制原子替换保护前一文档。恢复失败会禁用输入编辑，提供显式备份并重建操作。恢复先复制不可读取的加密字节，再提交空输入；替换失败不会发布空状态。读取绝不创建缺失的加密密钥；只有显式保存可以新建密钥。已保存状态可跨应用进程退出恢复；突然断电的持久性尚未验证。

重新配对先停止模型生产者并保存旧主体输入，再采纳身份。取消操作恢复同一主体已保存的输入和查看位置。新设备授权使用独立文档。进程在采纳后退出旧写入者，避免旧写入跨越持有者。[原生连接决策](2026-09-25-native-remote-connection-source.zh.md)拥有传输与模型持有提交的生命周期；[已保存 Host 目录决策](2026-09-26-android-saved-host-catalog.zh.md)拥有多 Host 选择及凭据采纳。[文件附件决定](2026-09-27-android-file-attachments.zh.md)拥有文档选择、上传及暂存回执过期。本决策继续拥有持久输入身份与恢复。

## 考虑过的替代方案

**只在模型或 Activity 状态中保留输入。** 这能跨界面重建保留输入，但不能在进程退出后恢复结果不确定的提交意图。

**自动重发恢复的 prompt 或回复。** 观察恢复不能证明修改失败。显式重试保留原 prompt 身份，让用户先检查 Host 结果。

**把不可读取输入当作空状态，或直接覆盖文件。** 解析、加密或写入失败时，这些做法会破坏恢复证据或最后的完整快照。显式备份重建与原子替换保留证据。

## 后果

编辑可能暂未保存；UI 区分保存中、保存失败和恢复失败。大小上限拒绝过大输入，不静默丢弃行。备份文件仍需后续明确的保留策略，应用不会自动删除。单元测试覆盖加密、主体隔离、严格解码、写入失败、保存状态、回执核对、修订归属及写入者退出。录制场景通过隔离验收应用的数据验证不同进程恢复、不自动提交和加密恢复。物理设备、硬件密钥永久失效及发布资格仍是独立工作。

[HTTP 响应清理决策](../bug-fix/2026-09-26-http-disconnect-response-retirement.zh.md)拥有调用方断开后迟到结果的清理。两个真实 Host 场景验证 prompt 准入后 Android 退出：显式重试复用已保存 id，只产生一次 inbox 插入、用户消息与模型回复；已有日志回执则直接清理待确认输入，不再发送 RPC。两者都在再次重启后保留新文本。
