# Agent Note: Android 支持导出区分 Native Gateway 与历史 Link 观察

Status: implemented

[English](2026-09-27-android-native-gateway-diagnostics.md) | 中文

## 问题

支持文档若只以历史 Link 客户端为生产者，就无法诊断当前原生连接。复用 Link 计数器和协议字段还会错误表达 HTTP 回调所有权、共享 mux 订阅及 API 协商。导出完整 Host 描述则会泄露身份与任意远端字符串。

## 决策

`WireDriving` 返回密封的 Native Gateway 或历史 Link 诊断变体。没有所有者时标记为 `WireDriving` 且不可用。直接使用的 Link 库 API 保持独立。支持文档保留 schema 版本 1：带生产者标记的诊断节新增 Native 变体，扫描器仍然只准入不可变字节，不解释这些诊断节。API 协议与持久 Session 版本保持为独立字段。

原生快照在既有生命周期锁内读取本地状态，不发请求、不建订阅，也不访问凭据存储。按客户端代次计数的 HTTP 统计包含配对和协商，排除 mux 流量，达到上限后饱和而非溢出，仅在所拥有的回调结束时计入完成。已注册逻辑订阅与正在退休的 mux 分别计数。模型生命周期内的重连计数仍由各模型拥有。

描述刷新记录查询状态与固定失败分类。刷新失败保留最近成功的协议观察；已退休客户端即使稍后完成取消也保持退休。配对时角色与成功描述均标记为最近已知：它们不能证明当前权限、Host 健康或持续连通。采集快照与显式请求刷新彼此独立。

原生能力详情复用该固定投影，不展示任意 Host 字符串，也不建立另一套观察服务。前台观察器将查询进度和保留事实发布到当前显示 Host 代次拥有的状态中。取消旧查询后，其迟到完成也不能发布到替代代次。打开或关闭详情不发查询；显式刷新和进入前台会查询，退到后台则取消请求。弹窗区分没有观察与已识别能力未被声明支持，失败后标明已有事实。该视图仅提供信息，不充当权限或操作可见性策略。

导出器只允许类型化角色、固定失败分类、已协商协议事实及客户端拥有的能力白名单。未知能力名称、Host 与设备身份、显示标签、来自 Host 的产品字符串、端点、指纹、凭据、载荷、路径和异常消息均不会进入这些诊断节。应用仍要求既有扫描器批准精确字节后才允许交付。

独立的[原生操作策略](2026-09-27-android-operation-capabilities.zh.md)将已识别能力用于操作呈现及发送前检查。其 Subagent catalog 标识也纳入固定诊断白名单；这不会改变诊断隐私规则，也不会把观察变为授权。

[传输决策](2026-09-25-native-remote-connection-source.zh.md)继续拥有 TLS、准入和退休语义。[模块迁移决策](2026-09-19-android-core-app-migration.zh.md)保留独立的构建与扫描器准入理由。两者均未被取代。扫描器源码出处与当前发布限制由 [Android README](../../../../apps/android/README.zh.md#known-limitations-and-deferred-work)拥有。

## 考虑过的替代方案

**将原生事实放入 Link 字段。** Link 请求计数与协议版本描述不同操作。显式变体保留各自含义，并防止同时提供两种传输快照。

**导出时查询 Host 或转储其描述。** 诊断读取必须在传输失败时仍可执行，且不能引入请求。完整描述含有任意远端字符串与身份；固定投影舍弃未知能力细节，以保留导出的隐私规则。

## 后果

带同步屏障的 HTTPS 测试验证未结束回调、查询取消、关闭后的迟到完成、挂起的 mux 订阅及等待静止的退休过程。精确 JSON 期望区分原生、历史及不可用生产者。已安装应用验收将实际原生观察送入捆绑扫描器，检查私有字段缺失，并在不发业务变更请求的情况下观察协商拒绝及恢复、测试拥有的逻辑 follow 中断。已安装 Compose 测试覆盖未知与保留事实、刷新禁用、Host 替换时关闭详情、旧代次迟到完成及前台取消；真实 Host 场景检查界面拒绝与恢复，确认没有业务变更。物理设备、崩溃采集、完整的能力驱动操作呈现和扫描器发布可复现性仍是独立验收工作。
