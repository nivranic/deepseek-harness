# Agent Note: Android 按所选父会话及视图生命周期持有子会话历史

Status: implemented

[English](2026-09-27-android-subagent-timeline.md) | 中文

## 问题

子会话目录属于用户打开的 Session。根据会话列表排序选择父会话，可能显示另一个父会话的子项。替换子视图时若不等待跟随与分页清理，导航后仍会遗留观察。已保存子会话是否可读，也不同于父 Agent 是否运行。

## 决策

Companion 将目录父会话、进度、行及父会话可用性一起发布。选择另一父会话时，先使旧读取失效，再发布新父会话的空目录。刷新各自拥有代次；取消使当前目录回到 idle，失败仅保留该父会话已接受的行。目录请求运行于受监督的模型生命周期，单次读取失败不会取消无关 UI 工作。Wire 解析拒绝无效或重复的子会话身份及不支持的行变体。

只有当前父会话目录中的子项能打开时间线。诊断行和旧父会话回调不发送请求。`parentAvailable` 描述父 Agent 是否运行，不能拒绝已保存历史。视图通过私有 Session 模型仅暴露重新连接和较早分页读取，保留有界日志及携带父会话地址的分页。它不暴露 prompt 或取消方法。

子会话替换、父会话选择、返回导航及 Host 模型销毁负责异步退役。替换等待跟随和分页全部清理；同步关闭使等待中的替换失效。已退役视图不能重连或分页。UI 仅在子视图的父会话与普通 Session 选择一致、且跟随能力仍可用时显示该视图。

[Session 历史决策](2026-08-18-session-history-and-event-transport.zh.md)保留协议和 Host 激活规则：普通 Session 跟随可在首个快照后激活父会话，直接子会话跟随保持冷读取。[原生日志决策](2026-09-26-android-native-view-location.zh.md)保留分页限制、游标恢复及固定截点语义。[操作决策](2026-09-27-android-operation-capabilities.zh.md)保留能力检查及 Host 授权。这些决策继续有效；原生子视图所有权不替代它们。

## 考虑过的替代方案

**选择会话列表首行。** 排序和刷新与用户打开的 Session 无关，可能静默更改父会话。

**向 Compose 暴露完整子 Session 模型。** 它的命令方法会使只读视图依赖呈现层自律。包装器仅暴露子会话历史允许的操作。

**要求父会话运行，或立即丢弃已取消任务。** 持久化子会话归属允许冷读取。请求取消不证明传输清理已完成，观察替换必须等待退役。

## 影响

核心测试延迟目录、跟随及分页完成，验证旧结果被拒绝和退役被等待；同时覆盖冷父会话可用性与无效 Wire 行。已安装 Activity 通过真实 Host 读取所选父会话的冷子会话，在固定截点分页，目录失败保留行，分页拒绝后重连，切换父会话时不激活子 Agent、不发业务写请求。场景保留普通父会话激活的可见事实。原生视图继续使用原始事件摘要；嵌套浏览、子会话续写、物理设备布局及 Swift 接入属于后续工作。
