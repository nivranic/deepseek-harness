# Agent Note: Host 发现使用持久身份与活跃 Remote 绑定

Status: implemented

[English](2026-09-16-host-description-and-capabilities.md) | 中文

## 问题

Client 生成的 Remote 导入描述的是自身选择的 API，而不是已连接 Host 当前挂载的能力。产品发布版本、API 代际与 Session 写入格式代际也回答不同的兼容性问题。启动竞争或存储失败时，标签或尽力持久化的遥测 id 无法提供持久 Host 身份。

## 决策

[`host.describe`](../../../../packages/api/host-description/README.zh.md)使用现有的认证 Typert Remote 路径。它返回持久随机 Host id、操作者标签、分别拥有的三类版本、Host 进程事实、已配置载体与当前显式能力 id。Host id 以配置文件为范围，不是设备凭据，也不是授权决定。创建复用共享文件锁与原子写入器；损坏和 I/O 失败会拒绝启动，不替换身份，也不临时生成仅在内存中的替代身份。

能力声明属于现有的 [`TypertGatewayBinding`](../../../../packages/typert/protocol/src/index.ts) 对象。每个带版本的语义 id 都列出其 owner 必须提供的导出方法。Gateway 只在所需方法定义全部可用时公布活跃绑定的声明。服务销毁与严格定义撤回都会移除可用性。重复 id、缺少导出和 provider 不一致都会显式失败。生成器接受这些运行时元数据，但不改变调用编解码器，也不放宽未知选项检查。

API Remotes 外观将生成的 `host` contribution 与已选择的业务 API 一起挂载。Session Controller 声明其跟随、实时控制、管理和模型选择操作集合。[Remote 方法决策](2026-08-02-typert-remote-method-calls.zh.md)继续有效：生成导入不能证明 Host 可用性，已撤回的严格定义不能回退到 SRC，能力也不能替代调用校验或授权。

Workspace 跟随、注册表管理和 Session 组织在 [Workspace Controller](../../../../packages/api/workspace-controller/README.zh.md) 中独立声明。Client 通过 Gateway 既有流生命周期等待跟随支持，不在连接准入时重复重启。Host 快照替换会清除投影与变更依据；待完成的一元响应不能更新新状态。UI 回调与目录接纳观察同一快照，投影不可用时保留浏览器视图偏好。已经派发的 Host 变更仍然生效；这些检查不提供变更回执或设备授权。

目录选择声明稳定后端能力实际服务的操作，而不是控制器导出的全部方法。原生选择、目录浏览与创建具有独立操作集。Client 仅在对应能力已声明时事务性注册流程，并把调用绑定到 Host 快照及注册生命周期。释放该生命周期会取消读取和原生选择；已经派发的创建仍可能提交，但迟到结果不能通过另一连接继续列目录或接纳路径。这样既保留 Host 已发生的变更，也不将它误当作 Client 当前的选择。

逻辑流准入与交付使用权威的 Connection 代次 id。过时代次的 Remote 失败不能终止面向替代连接的流，迟到帧在交付前丢弃。不同 Connection 获准后重置孤立重试计数，同一连接的重试限制及本地终止错误保持不变。Workspace 投影恢复因此仍由 Gateway 负责，替换期间的空投影不会因旧代次失败而成为 Client 的永久视图。

保留的交互回答归属于应用发现所校验的 Host 身份。仅凭事件 id 与 revision 无法区分通过同一载体访问的不同 Host。因此，Gateway 重放前要求显式回答 scope 与匹配的待处理快照；身份缺失时需由监听器重新作答。旧确认只能清除其自身的保留回答对象，避免过期连接清除替换 Host 的回答。这是内存重试的归属规则，不是设备认证、回答授权或持久化写入回执。

## 考虑过的替代方案

**从包版本或方法名推断能力。** 两者都不能标识带版本的业务承诺。显式声明让 owner 能命名完整操作集合及其支持的语义。

**维护另一套能力 registry。** Remote 绑定已随 Service 生命周期存在。第二条注册路径可能在实现消失后仍保留能力。

**复用匿名遥测 id。** 该 id 有意允许在持久化失败后使用临时身份，并在并发首次启动后逐步收敛。Host 选择需要稳定身份或显式失败。

**复用一个版本字段。** 包发布版本可以变化，而 API 或磁盘格式不变；Client 不得从其中一种版本推断其他代际。

## 影响

Gateway 的每条 RemoteStream 都在调用 opener 前等待已准入 Host，无论领域是否提供能力谓词。这避免首次发现仍处于连接中时，Workspace 启动流进入终止状态；就绪与重试仍由 Connection 负责。

Workspace 选择（包括复用空 Session）在建立导航意图前要求 `session.manage.v1`。创建与分叉在选中结果或搬移草稿前再次检查；能力撤回不会撤销 Host 已完成的变更。启动时自动选择会等待能力支持，并随 Connection 更新恢复，不重复待完成的请求。直接选中已有 Session 仍然可用。 Conversation 工作区选择器随能力撤回隐藏并关闭，恢复后不会自动重开。

Conversation 外壳从已准入 Host 信息派生一个 `historyAvailable` owner prop，传给选中 View。本地化提示区分历史不可用与加载中，同时保留缓存行和草稿。Chat 隐藏远端分页及未加载轮次导航；Trajectory 保留本地分页但停止 Host 历史读取。浏览器回归通过受控能力声明，在真实 Host 上验证实际载体替换及历史追赶。

侧栏的 New Session 快捷入口要求 `session.manage.v1`。现有渲染器绑定从已准入 Host 信息派生的布尔值，连接替换时重新检查可用性，不增加第二份存储。品牌标识和非创建导航仍然可用，保留的新建回调在能力撤回后不能发起导航。Workspace 行创建以及分组和单列表中的 Session 重命名、分叉使用同一已准入能力。撤回会关闭已打开的 Session 菜单和重命名对话框，恢复后不会重新打开它们。预设 Settings 创作入口在预置预设或导航前检查能力；其渲染器 hook 会隐藏该操作，同时保留普通预设操作。

Session Controller 与 Client 准入共享显式能力声明。Gateway 在单次调用或流派发前检查每个已声明的 Session 操作，因此隐藏的 UI 与保留的回调使用相同操作策略。控制流和事件 journal 分别等待具备各自能力的已准入连接代次，而不将能力缺失视为流的终止失败。Journal 在等待期间保留已发布窗口，恢复后再替换；销毁会释放等待订阅。Conversation 控件在保留草稿的同时进入只读状态，并在具备能力的连接代次到来后恢复；重连仍由 Connection 负责。

Client 组合在暴露所选业务 namespace 前安装发现逻辑。Gateway 使用现有 Connection 本次尝试的取消信号，在打开转发事件流前执行发现；业务调用同时等待发现完成和事件就绪。描述信息归属该代际，因此代际失效会清除公开的事实并取消其已放行调用。等待中的调用方可独立取消。发现责任方撤回后准入保持关闭，已取消尝试的迟到结果不能发布就绪状态。Connection 仍是唯一的重试责任方。

生成的结果编解码器校验发现响应；先检查 API 判别字段，使未知代际返回明确的不兼容结果，而不应用当前代际的其余编解码器。发现表示保持协议 1，以支持封存 Client。显式协商提议选择最高共同请求编解码器 2 或 1；缺少协商元数据标识协议 1 Host，不探测不可用方法。元数据矛盾、身份变化或协商失败均拒绝准入，不降级。发现不授予权限。原生 DTO 消费方、基于能力的 UI 准入以及专用升级界面仍未完成。Session 事件与磁盘格式保持不变。

单元测试覆盖身份竞争、持久化失败、能力撤回，以及生成调用声明保持不变。真实 Web Loader 测试经过认证 HTTP Remote 路由，拒绝匿名发现，并将返回身份与隔离 Harness-home 文件对照。Desktop 载体配置单独检查；这些结果不构成新安装包、原生 Companion 或真实模型执行的验收。

Gateway 在 Host/Client 共用的协议模块中拥有载体请求版本解析。版本 1 编码器保留不带版本字段的参数 envelope；版本 2 携带显式判别字段。一元与流分发都在端点处理前校验显式版本，包含保留事件端点。未知版本不能调用业务方法或注册事件 Client。应用准备回调显式返回已选编解码器，每个代际为业务调用与事件回复持有该值。协商不授予权限。真实 HTTP 测试双向执行当前与封存协议 1 API bundle；共享 workspace 依赖保持不变，此证据不构成完整旧发布版本验收。

模型选择在渲染两个入口或读取目录前检查已准入的 `model.select.v1` 事实。目录执行方再次检查可用性，防止保留回调发送不受支持的操作。slot renderer 直接绑定 Host 代际的 observable，不维护独立能力存储。代际失效清除旧目录与路由阻塞，命令 owner 关闭该代际的弹窗而不移动焦点。能力存在仍不授予操作权限。其他功能入口仍需各自接入能力准入。

Agent Presets 通过现有 Remote 绑定分别声明目录、选择与管理能力，Client 准入消费同一纯声明模块。目录能力缺失时不探测名单或目录打开器，并撤回 Settings 注册；已声明操作的调用失败仍是错误。选择能力撤回会丢弃暂存选择，管理能力撤回会关闭复制和删除草稿，保留回调在派发前检查当前事实。历史标签仍由投影拥有。这让缺少选择或管理能力的 Host 保持目录可读，且不增加能力存储或重试所有者。Settings 偏好及目录能力由另一所有者负责，预设操作集不保证这些操作的授权。

Settings Controller 通过既有绑定独立声明脱敏读取、写入、配置文档打开及预设目录操作，Gateway 检查对应拥有方的操作集。预设偏好与位置控件分别检查 Settings 支持，不以预设目录或管理能力代替；偏好写入不可用时不能触发空白 Session 同步，复制预设也不要求或探测目录打开 API。声明保证可调用语义，提供方缺失、可写性、原生打开策略及权限仍由具体操作检查。其他能力所有者仍需各自补齐依据能力控制 UI 的行为。

共享 Settings 镜像在派发前依据当前 Host 能力准入读取。Connection 替换会清除文档，有效可写性同时要求 Host 支持与提供方可写，按命名空间的 scope 保留显示值但清除旧修订号的效力。写入要求同一代次已接受的命名空间，早到操作与旧代次排队写入不会在新 Host 上重放；迟到结果不能发布或为下一代次提供修订栅栏。配置文档入口还检查元数据代次与文档打开能力。冷启动在发现后只开始一次共享 describe，不在准入前试探读取。实现复用既有镜像、队列和 Connection 失效事件。

LLM 与凭据绑定现在分别拥有目录、发现、元数据和写入能力集合。Models 聚合在派发前准入读取，已准入 Host 快照变化时清除旧视图。编辑器回调捕获该快照，既有页面投影提供代次标识以在替换时丢弃本地编辑器与密钥草稿，防止迟到的第一步结果经新连接发送第二步写入。缺失 API 会移除相应入口，提供方权限检查保持独立。其他能力所有者、完整兼容与错误覆盖、Device Trust 执行仍未完成。

Web-search 配置消费者现在在当前 Settings 命名空间接受后遵循凭据所有者的能力声明。Connection 替换会销毁控制器和暂存密钥状态，同一引用的读取序号阻止迟到元数据替换较新答案。共享卡片表单在 scope 失去已接受命名空间或所有者销毁表单时，使多步保存失效；普通插件卡片写入也由此获得跨重连保护，并保留保存开始后的新输入。API 支持、提供方可写性与 Host 权限保持独立。

Workspace Files 拥有独立的操作声明。Client 文件提供方要求元数据能力，捕获已准入的 Host 快照，并在替换时取消注册所属的操作。仅支持元数据的 Host 产生单次 stat；变更能力增加既有的 Session 共享流与就绪顺序。替换后仍被持有的资源重新 stat，避免断连期间漏掉的写入使旧元数据版本继续有效。等待前驱关闭时被取消的流不再派发。文件系统访问、文件列表 UI 与渲染器入口决策仍分别负责。

文件列表与文档预览注册现在属于已准入的 Host 快照。列目录、元数据、文本分页和完整字节分别判断，HTML 声明额外的关联文件要求。撤回会移除操作入口，保留 tab 的身份仍由 Sidebar 拥有。替换会取消旧读取并丢弃所属内容 store，避免重连后保留过期文件内容。渲染器可用性变化通知 tab 注册表而不替换 tab；注册拥有该观察器，失败时回滚。关联文件读取器也捕获注册生命周期并拒绝迟到结果。输入框引用与已发送消息中的文件、技能标签，从同一查看器注册表推导可用性。InputTrigger 发布来源、词表和查看器变化；只读可用性查询不发起请求，执行入口再次检查。技能预览要求已加载的目录路径，目录仍由正常预热和菜单发现负责。可用性不进入草稿序列化或 Session 历史。Chat 通过 renderer hook 绑定这些观察值，并随读者释放可选来源订阅。工具路径摘要、产出文件标签、显式交付预览与收尾正文通过既有 Tool 和 Turn-tail props 使用同一所有者查询。撤回保留文件名、结果展开操作和持久事实，只移除预览控件；已解析的正文操作也再次检查可用性。原生文件菜单保留其独立的 Host 元数据与操作策略，其他能力所有者仍待处理。

引用发现保留已注册来源，因为来源同时负责草稿序列化和预览路由。文件、会话和技能发现分别要求各自所有者声明的能力，不通过失败调用探测功能。候选失效采用独立于词表变化的订阅，同步取消旧查询并移除候选及面包屑。连接就绪会重新预热来源，使发现前被抑制的目录无需再次按键即可可用。文件预览资格仍由查看器决定，技能预览还要求当前已完成的目录。迟到响应不能恢复旧 Host 的目录或候选。

延迟候选刷新属于菜单查询代次，不属于解析器产生的某个命中对象。来源失效在等待其他观察者时，编辑器可能重新识别等价命中；此时保留查询并使用最新范围。新查询、关闭菜单或销毁仍会拒绝排队刷新，防止已失效菜单在没有活动候选请求时永久停留于等待状态。

原生交付操作使用既有所有者的生成式 Remote contribution，使 Host 发现可从活动方法推导桌面元数据、打开和显示位置能力，无需第二个注册表或后备 HTTP 路由。每项操作保留 Session 事件归属、文件系统到 Host 的路径映射及原生策略检查。Client 要求已接受的当前代际元数据和具体操作能力，缺少任意条件即移除入口。代际丢失取消元数据与原生请求、清除临时状态、拒收旧结果，不重放用户操作。结构化错误区分文件不存在、桌面不可用和原生路径不可用，且不泄露私有路径。超时依赖分类通过 peer 安装保持唯一的 `TimeoutReason` 身份，不增加重复安装豁免。

Session 搜索和持久化图片读取在既有 Remote 所有者上声明独立操作能力。Gateway 继续统一负责准入和代际取消；Session 层不增加第二套连接生命周期。Workspace 搜索观察 Connection 代际的即时撤销，保留本地元数据匹配和查询文本，并在支持恢复后只重读当前查询。同样具备搜索能力的新代际也会使已完成的旧内容结果失效。附件能力准入不能替代 Session 日志授权。

Settings 镜像订阅 Connection 代际变化，因此撤销会在重连完成前清除共享文档。权限默认值编辑器要求描述及两项 Settings 能力均来自当前代际。进行中的写入保留其发起 Host；替换会丢弃旧成功或失败且不重放，新代际的独立选择仍可执行。销毁拒绝新操作并等待待完成写入。测试夹具显式声明 Settings 支持，不以命名空间存在代替准入。

Client 原生操作通过声明文件所有者接收持久化文件声明坐标。Session Controller 的原生路径打开与桌面元数据仅供 Host 服务本地调用，生成的 Session 命名空间不导出这两类辅助方法；无使用方的可用性查询已移除。这避免了并行的任意路径 Remote API 绕过声明文件授权流程。生成的 Client 类型、受控 Connection fixture、已认证 HTTP 路由和 Gateway 直接派发均拒绝这些本地方法名；Host 适配器测试保留打开和显示位置行为。

Commands 分别声明目录与执行能力。既有 Connection 代际源立即使目录和候选菜单失效，目录 epoch 继续负责普通软刷新。等待目录的 Enter 判定不能采用替换连接的目录；保留的输入声明和 Host 候选绑定起始 Host 身份。迟到的执行成功或失败不能确认新提交，分离执行的旧回执不发布过时通知。传输取消仍由 Gateway 负责。独立 Client 贡献项按自身谓词保持可用；Host 装饰要求当前可执行描述符。真实 Host 浏览器用例在隔离命令处理器运行后延迟回执送达，再撤销能力：草稿保留，恢复后没有第二次执行请求。该观察证明响应归属和不重放，不代表回滚 Host 已接受的变更。

Goal Remote 操作分别声明能力，领域层继续负责 revision 与状态转换校验。目标栏同时要求读取能力和各动作声明，激活源观察 Connection 的即时撤销。受支持回调先捕获 Host 身份，再读取当前投影 revision 并调用既有 Remote 方法。替换权限快照给 GoalBar 新组件 key，明确丢弃 Host 所属编辑器与等待状态，同时保留独立消息输入框。旧动作结果不能关闭替换编辑器或隐藏其目标。激活源容纳传输拒绝并抑制不受支持的读取，运行期激活和持久化阶段保持独立。浏览器用例播种未激活 Goal，接受一次真实编辑，在重连时取消送达，并保留独立打开的替换编辑器且不重放。

Subagent 目录、提示词与父级寻址中断分别声明操作能力。目录撤销清除瞬态成员、父级可用提示与打开菜单，同时保留持久子级地址、已选 Session 及其草稿。目录请求同时拥有代际和待完成槽位，旧请求结算不能移除替换请求。输入框分别解析 prompt 与 Stop 控件，一次性记录保持只读。Stop 回调捕获 Host 与子级地址，子级提交在图片序列化和响应结算前后检查 Host 身份。这些 Client 检查阻止过期派发和 UI 发布，不回滚 Host 已接受的变更。[继续执行所有者](../feature/2026-07-28-continuable-subagent-conversations.zh.md)识别重复的 Prompt 身份；按目标中断捕获已观察的子级轮次，旧方法保留当前轮次语义。持久父子归属与在线激活仍由 Host 负责。

Feedback 操作分别声明消息读取、写入、删除和 Session 备注记录能力。Client 在消息 CAS 变更前要求读取；只读评分保持静态展示，不支持的读取不探测 Host。既有 Connection 撤回会清除条目版本、排队操作归属、弹窗与提示。读取和变更在等待前捕获起始 Host，旧响应不能替换当前版本或释放替换请求。弹窗使用独立连接 epoch，使同一连接内关闭草稿后仍能确认已提交备注，而被替换连接不能发布确认。这保留既有消息持久化和 Session 仅记日志语义，不引入重放，也不声称幂等性。

文件暂存的生成 Remote 与原始字节载体共用 owner 能力声明。Client 上传服务依赖 Connection 与 Gateway 类型，不依赖应用 Remote 组装，因此共享的能力缺失错误码由 Gateway 持有。取消起始代际会阻止旧传输接纳回执；输入框还使已完成回执失效，因为这些回执已没有活动请求可供取消。浏览器持有的文件和图片仍保留为草稿，但支持恢复不会自动重新暂存。原生选择器回调与附件序列化保留起始 Host 身份。这些规则阻止跨连接发布与重放，不代表回滚已存储字节。

插件清单独立于预设和 Settings 访问声明只读能力。设置页标签注册归属一个 Connection 代际并捕获其 Host；替换连接即使保留相同能力集合，也通过新组件身份重置 Host 所属的搜索、选择、展开与菜单状态。撤回会取消读取并移除入口；保留的回调在派发前拒绝，迟到结果不能进入替换页面。Host 在预设发现前后检查取消，不引入第二套 Loader 缓存。

动态 Cordis 操作独立声明，因为清单与检查可以在不支持执行或变更时可用。双半部运行在首次 Host 激活前准入其必需步骤。页面编排器与加载引擎分别持有 Connection 代际：撤回前者会阻止后续 RPC 和旧尝试结算，撤回后者会阻止迟到的模块注册并使旧 Client 代码持有的闭包失效。逐 Plugin 队列保留替换加载前的拆除顺序。inspect 发布会丢弃旧排队工作，使替换发布不受先前停滞读取阻塞；查询清理核对精确 controller 归属。这些 Client 生命周期不会回滚 Host 已接受的激活。

动态 Cordis 面板与补全源也归属于一个代际。即使替换连接具备相同能力，新的注册也会重新挂载面板，使旧选择、错误和待处理回调无法取得新清单。已记录工具卡片的归属仍由 Session 决定。拒绝独立于激活：声明请求确认的 Host 可以展示待审批请求，而不允许页面启动它们。包级操作要求由 [UI 参考](../../../../packages/extensions/ui-cordis/README.zh.md)维护。
