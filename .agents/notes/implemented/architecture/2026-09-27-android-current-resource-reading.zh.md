# Agent Note: 原生文件与交付预览共用当前 Host 的有界读取

Status: implemented

[English](2026-09-27-android-current-resource-reading.md) | 中文

## 问题

按历史工件 id 查询的工件页无法解析当前 Host 的文件交付。无界字节缓存会让大文件耗尽移动端内存；文件变化后继续拼接则会混合不同版本。原生伴随端需要采用当前客户端使用的 Session 作用域文件操作。

## 决策

Android 将持久 `deliverables/presented` 声明投影为文件引用，以事件序号和原始文件索引标识。路径保留原始拼写，可选描述仍是模型撰写的文本。声明不授予权限：所选 Session 和 [workspaceFiles 命名空间](../../../../packages/api/workspace-files/README.zh.md)决定文件访问。应用不再包含 `session/artifact` 读取或按工件 id 缓存字节。历史 Lite 存储和折叠保留为独立协议夹具。

工作区条目和声明的交付共用一个原生读取器。它先调用 `workspaceFiles/stat`，再串行请求 `workspaceFiles/readBytes` 窗口。描述符保留 Host 的绝对路径、不透明版本和可选的完整字节大小。每个响应必须保留这些字段、匹配请求偏移、解码规范且有界的 base64，并保持一致的 EOF 进度。读取失败只保留已接受字节；显式重试重新 stat，并从首个缺失字节开始。描述符变化会丢弃前缀，要求重新打开。

应用提供限制：64 KiB 窗口、8 MiB 内容保留预算、256 字节前缀。已知更大的文件只请求该前缀；大小未知的文件在保留预算处停止。两者都报告预览不完整。分块拼接完整内容时可能额外分配一份有界副本；这些计数不是总堆内存上限。呈现另将文本限制为 64 Ki 字符，图片解码限制为四百万像素。不支持或无效的内容保持为惰性十六进制前缀；HTML 和 SVG 不执行。

替换或关闭选择会取消所属读取。取消任务在结束前仍被持有，代际检查拒绝迟到发布。模型退出等待请求清理。应用切换 Session 时，即使其他标签页正在显示，也会关闭上一资源。解码位图只对产生它的同一个字节数组显示，避免新选择期间出现上一张图片。

[原生传输决策](2026-09-25-native-remote-connection-source.zh.md)继续拥有 TLS、准入和模型生命周期。[查看位置决策](2026-09-26-android-native-view-location.zh.md)继续拥有 Session 历史保留。本决策扩展其消费者，不取代这些独立依据。

## 考虑过的替代方案

**恢复平行的工件 id 服务。** 当前文件交付以 Session 文件系统作用域内的路径标识文件。第二套服务会重复授权，并保留不可用的应用协议。

**将所有文件读入内存，或不重新 stat 就续传。** 无界内容超出移动端预算；保留前缀不能与已变化版本的字节拼接。有界预览和显式重启保留真实的完整性与版本信息。

## 后果

核心覆盖空文件、中文文件名、范围校验、中断读取、描述符变化、字节预算、当前交付投影、Session 替换及等待取消结束。安装应用验收使用真实 Host 操作、生成文件和预置的当前交付事件，包含图片像素拒绝与大文件前缀。真实模型、物理设备、持久下载、SAF 导出、相机/照片附件、Swift 采用及全平台描述符验收仍是独立资格工作。
