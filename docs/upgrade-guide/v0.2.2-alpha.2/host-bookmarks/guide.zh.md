# 在独立页面打开各个 Host

[English](guide.md) | 中文

## 变更

主机设置分区保留书签、名称和排序，不再提供页内“切换”或“回到本页 Host”操作。官方 Web 连接始终使用页面 origin；当前 Host 标记跟随经过认证的发现结果，而非已保存的选择。

## 迁移

1. 打开设置 → 主机。现有 `dsh-saved-hosts.v1` 书签无需转换，本地名称和顺序保持不变。旧的 `dsh-selected-host.v1` 值将被忽略。
2. 对其他 origin 使用**打开主机页面**。如果访问被拒绝，请获取该 Host 当前的启动链接；书签不等于授权。
3. 连接后确认当前 Host 标记。如果发现失败，书签仍可见，但不会声称已确认当前身份。重命名或忘记书签不会切换或断开本页连接。
